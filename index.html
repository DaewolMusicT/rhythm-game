학생에게 문제 배포

문제를 저장한 뒤 학생용 링크를 만들어 배포하세요. 학생에게는 출제 탭과 템포·통과 점수 설정이 보이지 않습니다.

링크에는 문제·템포·통과 점수가 포함됩니다. 수정 후에는 새 링크를 만들어야 합니다. 너무 긴 링크는 문제를 나누어 배포하세요.

1. 단선 카혼 리듬 만들기

선은 하나입니다. 오른손은 선 바로 위에 닿는 음표와 위쪽 쉼표, 왼손은 선 바로 아래에 닿는 음표와 아래쪽 쉼표로 표시합니다. 두 손은 각각 4박을 완성해야 합니다. 가장 긴 음가는 4분음표입니다.

입력 성부

오른손 0 / 4박 · 왼손 0 / 4박

위쪽 또는 아래쪽 음표를 클릭하면 해당 손의 그 음표부터 뒤를 지울 수 있습니다. 8분·16분음표가 연속될 때는 빔으로 연결됩니다.

2. 저장된 문제 (0개)

문제와 설정은 현재 브라우저에 자동 저장됩니다. 기존 리듬 챌린지 저장 데이터는 삭제하지 않습니다. JSON 백업을 권장합니다.

학생 정보

학생 정보는 이 기기에만 저장됩니다. 결과는 다운로드하거나 복사하여 제출할 수 있습니다.

문제

악보 읽기: 선 위 = 오른손(슬랩), 선 아래 = 왼손(베이스). 각 손의 쉼표에서는 해당 손을 누르지 마세요.
오른손 Enter   왼손 Space   시작 S 또는 버튼
시작하면 4박 카운트다운 이후 1마디를 연주합니다. 길게 누르지 않고 음표 시작점에서 한 번씩 누르세요. 동시에 치는 음표는 두 키를 함께 누릅니다.

시작을 눌러 주세요.
