학생에게 문제 배포

문제를 저장한 뒤 학생용 링크를 만드세요. 사이트를 인터넷에 게시한 후 생성한 링크를 학생에게 전달하면 모든 학생이 같은 문제를 풉니다.

링크에 문제와 템포가 포함됩니다. 문제를 수정하면 새 링크를 만들어 다시 공유하세요. 이 버전은 실시간 교사 대시보드는 제공하지 않습니다.

1. 리듬 만들기

음표/쉼표를 선택해 왼쪽부터 추가하세요. 한 마디(4박)가 채워지면 저장할 수 있습니다. 악보의 음표를 클릭하면 그 위치부터 지울 수 있습니다.

현재 0 / 4박

2. 저장된 문제 (0개)

문제와 설정은 현재 브라우저에 자동 저장됩니다. 다른 PC로 옮길 때는 JSON 내보내기/불러오기를 이용하세요.

학생 정보

학생 정보는 이 기기에만 저장됩니다. 결과를 제출할 때 선생님에게 보여주거나 파일을 전달하세요.

문제

시작 버튼을 누르면 준비 카운트 4박 후 연주가 시작됩니다. 각 음표의 시작 시점에 스페이스바를 짧게 누르세요. 쉼표에서는 누르지 않습니다. 2분음표는 한 번만 누릅니다. 박자 클릭음이 들립니다.
